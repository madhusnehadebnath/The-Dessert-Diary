# PROJECT: THE DESERT DIARY — PREMIUM 3D HOME BAKERY WEBSITE

You are an expert senior web designer, frontend engineer, UI/UX designer, motion designer and creative developer.

Build a production-quality, responsive website for a premium home bakery called:

**THE DESERT DIARY**
**by SS**

Brand tagline:

**“You bring the occasion. We’ll bring the cake.”**

This is a real small home-bakery business. The baker takes customer orders, creates cakes from home and may personally deliver them.

The attached assets contain the bakery's existing visual identity:
- Final promotional poster
- Final landscape shop hoarding
- Menu/catalogue
- Original cake photographs
- Other bakery visual references

IMPORTANT:
Study all attached assets before designing anything.

The website MUST feel like an extension of the existing brand, not like a generic bakery template.

---

## 1. CORE CREATIVE DIRECTION

Create a sophisticated, elegant, feminine and premium bakery website.

Visual personality:

- Soft
- Romantic
- Elegant
- Warm
- Handmade
- Premium
- Artistic
- Whimsical
- Modern
- Slightly luxurious

Primary visual palette should be inspired by the existing materials:

- Blush pink
- Soft pastel pink
- Warm cream
- Ivory
- White
- Very subtle champagne/gold accents
- Deep berry/rose pink for important typography and CTAs
- Soft brown/charcoal for readable body text

Do NOT make the website overly saturated.

Do NOT use a generic pink bakery template.

Do NOT make it look childish.

Do NOT use excessive gradients.

Do NOT use excessive glassmorphism.

Do NOT use excessive shadows.

Do NOT fill every section with animations.

The final result should feel like:

**a premium boutique patisserie website combined with a beautiful modern portfolio.**

---

# 2. MOST IMPORTANT DESIGN RULE

The attached cake photographs are the actual cakes made by the baker.

Use those photographs prominently.

Do not replace them with:
- stock cake photographs
- random internet images
- AI-generated cake photographs
- placeholder cake images

If an image needs editing for presentation, use tasteful cropping, masking, background removal or subtle enhancement while preserving the original cake.

The cake itself must remain authentic.

Create a visually impressive hero section.

Desktop:

- Full viewport hero
- Elegant cream/ivory background
- Soft floral artwork inspired by the attached hoarding
- Large elegant “The Desert Diary”
- Smaller “by SS”
- Tagline underneath
- One or two beautiful authentic cake photographs
- Strong CTA buttons

Primary CTA:

**Explore Our Cakes**

Secondary CTA:

**Order Your Cake**

Possible supporting line:

Typography should be elegant but highly readable.

# 5. BRAND INTRO ANIMATION

Create a tasteful initial entrance animation.

When the website loads:

1. Soft cream background appears.
2. Small decorative floral/heart element fades in.
3. “The Desert Diary” elegantly reveals.
4. “by SS” appears.
5. Tagline fades upward.
6. Main hero imagery gently enters.
7. Navigation becomes visible.

Keep the animation short.

Do NOT create a long loading screen.

Do NOT make users wait several seconds before accessing the website.

Respect `prefers-reduced-motion`.

# 9. 3D / IMMERSIVE EXPERIENCE

The website should have tasteful 3D elements.

Do NOT turn the whole website into a video-game environment.

Use 3D where it adds value.

Possible 3D/immersive elements:

### Hero
Layered cake imagery with depth/parallax.

### Floating decorations
Very subtle floating:
- petals
- tiny hearts
- sparkles
- crumbs
- soft flour particles

### Cake showcase
Create a premium 3D-like presentation using layered imagery and depth.

If actual WebGL/Three.js is used, keep it lightweight.

Potential technology:

- Three.js
- React Three Fiber
- Framer Motion
- GSAP

Choose technologies based on performance and reliability.

Do not add a heavy 3D library simply for the sake of saying the site is 3D.

The website should still load quickly.

# 16. RESPONSIVE DESIGN

The website must be designed mobile-first.

Test:

- Desktop
- Laptop
- Tablet
- Mobile

The mobile version must NOT simply be a compressed desktop layout.

On mobile:

- Typography scales correctly
- Images remain attractive
- Navigation becomes hamburger
- 3D effects are reduced where necessary
- Animations remain smooth
- Buttons are thumb-friendly
- No horizontal scrolling
- No text overflow

---

# 17. PERFORMANCE

- WebP/AVIF where appropriate
- Lazy loading
- Responsive images
- Proper image dimensions
- Code splitting where useful
- Efficient animation
- GPU-friendly transforms

Avoid:

- unnecessary JavaScript
- huge libraries
- autoplay heavy videos
- excessive WebGL
- huge unoptimized images

The website should feel premium AND fast.

# 26. DEVELOPMENT PROCESS

Do NOT generate the entire application blindly in one pass.

First:

1. Inspect all attached assets.
2. Identify the brand colors, typography style, visual motifs and cake categories.
3. Create the design system.
4. Create the website architecture.
5. Build the homepage.
6. Add cake catalogue.
7. Add custom cake section.
8. Add gallery.
9. Add ordering/contact functionality.
10. Add animations.
11. Optimize mobile.
12. Test everything.

After each major stage, check for:
- visual consistency
- responsiveness
- broken images
- console errors
- accessibility problems
- performance problems
- animation glitches

If an existing implementation already exists, improve it instead of unnecessarily rebuilding it.
