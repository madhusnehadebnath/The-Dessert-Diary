# DESIGN PRINCIPLE

The hierarchy should always be:

**CAKE → BRAND → STORY → INFORMATION → ORDER**

The cakes should remain the visual hero.

Do not let animation overpower the product.

# RESPONSIVE BREAKPOINTS

Desktop:
1440px+

Laptop:
1024–1439px

Tablet:
768–1023px

Mobile:
<768px

Mobile should receive a deliberately designed layout rather than simply shrinking the desktop version.

# COMPONENT PRINCIPLE

Each major section should be an independent reusable component.

Cake products should be data-driven.

Business information should be data-driven.

Animations should be reusable.

Images should be optimized.

This makes future maintenance easy.
